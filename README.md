# うちかえる

「うちかえる」は、迫るカエルの大群を拠点の自動攻撃で撃退し、ランダムに提示される武器・強化カードを選びながら 60 波クリアを目指すスマホ向けブラウザ防衛ゲームです。

公開 URL: https://chameleonjp.codeberg.page/uchikaeru/

## リポジトリ構成

- `index.html`: HTML / CSS / JavaScript を同梱したゲーム本体。ビルドなしでそのまま配信します。
- `README.md`: 仕様、ランキング連携、修正履歴を記録するドキュメントです。

npm、Vite、外部ビルド、複数ファイル化は使わず、`index.html` 1 ファイル構成を維持します。

## ゲーム仕様

- ゲーム名: うちかえる
- `game_slug`: `uchikaeru`
- テーマ: 画面上側から迫るカエルの大群を、画面下側の拠点から自動攻撃で撃退します。
- 目標: 全 60 波クリア。
- 武器: 8 カテゴリ × 5 種類の合計 40 種類。
- カード選択: 各波クリア後に 3 枚の候補から 1 つ選択します。
- 初回武器: 名前入力後の 3、2、1 カウントダウン後、1 波目の前に攻撃可能な武器だけを 3 枚提示し、1 つ選んでから 1 波を開始します。
- 敗北条件: 拠点体力が 0 になると結果画面へ進みます。
- リタイア: プレイ中にリタイアした場合も、クリア済み波数とスコアで結果を確定します。
- 性能上限: 敵 80 体、弾 120 発、エフェクト 120 個。

## ランキング仕様

ランキングは Supabase の共通 RPC を使うベストスコア型・降順です。結果画面にランキング登録ボタンは置かず、RESULT 確定後に自動で 1 回だけ送信します。

送信値は波数を最優先するため、次の整数を使います。

```text
rankingScore = clearWave * 100000000 + battleScore
```

画面表示やシェア文では巨大な送信値をそのまま出さず、必ず次の形式に分解します。

```text
○波クリア / ○○点
```

0 波クリア、敗北、リタイア、60 波クリアのいずれでも同じ形式で表示します。

## Supabase 連携仕様

- Supabase URL: `https://mlpnjgezrnhdxsxolyzj.supabase.co`
- 使用キー: Publishable key のみ。
- secret key / service_role key は使用しません。
- `public.scores` は使用しません。
- 送信 RPC: `submit_score`
- ランキング取得 RPC: `get_best_score_ranking`
- 共通仕様上の関連 RPC: `get_first_try_ranking`, `get_game_play_stats`

スコア送信では、`p_display_name`, `p_game_slug`, `p_score`, `p_client_version` を渡します。ランキング取得では `p_game_slug` と `p_limit` を渡します。送信や取得に失敗しても結果画面とシェア機能は壊さず、無限再送もしません。

## 今回の修正内容

- ゲームループを `loop()` 末尾の `requestAnimationFrame(loop)` に集約し、`draw()` から次フレーム呼び出しを削除しました。
- ホーム画面など `state.run` がない状態でもループが継続するようにしました。
- RESULT 後は `update()` が進まないため、敵移動、弾移動、当たり判定、スコア加算が止まります。
- 初回カウントダウン後に攻撃可能な武器だけを 3 枚提示し、選択後に 1 波目を開始するようにしました。
- Supabase URL と Publishable key を設定し、独自 RPC 名から共通 RPC 名へ修正しました。
- DOM の id 自動グローバル参照に頼らず、`document.getElementById()` で明示的に取得するようにしました。
- ゲーム画面を表示してから次フレームで Canvas サイズを取得するようにしました。
- `READY` / `PLAYING` / `CHOOSING` が同じゲーム画面を共有しても、画面切り替えで非表示に戻らないようにしました。
- 「他のゲームで遊ぶ」リンクを実験場 URL に合わせました。

## 動作確認観点

- ホーム、ルール、名前入力、カウントダウン、初回武器選択、プレイ、波クリア後カード選択、結果画面へ進めること。
- 名前未入力では開始できないこと。
- 候補選択中と RESULT 後に敵・弾・当たり判定・スコア加算が止まること。
- `requestAnimationFrame` が二重起動せず、ループが止まらないこと。
- iPhone SE 幅で横スクロールせず、Canvas とカードが重ならず、下部ボタンが押せること。
- ランキング表示が `○波クリア / ○○点` 形式になること。
