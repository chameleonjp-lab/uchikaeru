## 変更と不変条件

ホームの任意名を開始時に確定し、名・公開参加・UUID・クライアント版をそのプレイへ固定する。空白のみは非公開であり、後から名を付けても過去ゲスト結果を送らない。10文字制限はUnicodeコードポイントで扱い、IME変換中のEnterを無視する。旧 `uchikaeruName` をそのまま読み書きし、消去も保存する。

サーバーの記録・game_slug・採点・モード・敵/弾/演出/武器の上限・武器性能・ランダム3択・60波・HPボーナスを変更しない。`rankingScore=clearWave*2000000+min(1999999,detailScore)` を保持する。60波・実詳細2,037,256点の結果は実点数を表示し、送信値だけ121,999,999へ丸める。リタイアは既存どおり到達済み波/点数で確定する。名前あり0波リタイアも0点送信対象であり、クリアとは表示しない。匿名開始・集計RPCは元々なく新設しない。

結果は通信前に端末へ保存する。名前あり結果の送信は `submit_score_once_shared_v1` へ固定UUIDで行い、ACK紛失・失敗・再読込も同じpayloadを再試行する。結果の言語変更/再表示は新規送信を作らない。過去の未送信はUUIDごとのキーに残し、次プレイや名前変更で上書きしない。ACKの名・整数スコア・回数・重複判定を確認し、確認できたIDだけ削除する。通信待ち/送信中/失敗/送信済みを区別。8秒でRPCを中断し、再試行できる。旧非冪等RPCには戻さない。

上位30件は既存の参加者集計 `get_best_score_ranking` にlimit30を指定する。元の`rank_no`と順序を維持し、同名の別行を除去したり、自分と推定して装飾したりしない。形式不正のHTTP200は取得失敗であり、推測順位・0点へ補正しない。読み込み/空/失敗/再試行を用意し、新しい要求以外の遅い応答を反映しない。送信ACK後に再取得し、古い読取結果に戻らない。

言語は同期のインラインカタログで起動し、保存選択→対応ブラウザ言語→英語を使う。翻訳による再抽選・時間の巻戻し・スコア消去・送信はない。カードは内部ID/typeで処理し、名前・カテゴリ・説明だけを翻訳する。このゲームは日本語文字判定問題を含まない。翻訳の長さによる読みやすさは確認したが、母語話者による自然さの校閲は未実施。

ホーム/結果のXは黒地白文字、紹介文/今回実結果と現在正式URL。名前・推定順位・参加人数を含めない。X投稿画面を開くだけで投稿済みとは表示せず、開けない場合はコピー用ダイアログが使える。
